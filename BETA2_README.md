# Roadmap Beta 2 local experience

## Start

1. Extract the complete ZIP.
2. Double-click `BETA2_START.cmd`.
3. Keep the separate **Roadmap Beta 2 server** window open.
4. Use the guide page and the coach workspace that open automatically.

Node.js 22.13 or newer is required. The first launch installs the exact locked dependencies and builds the application.

## What to evaluate

- Can the coach understand what deserves attention?
- Does creating the first roadmap feel like a short coaching conversation?
- Does the player workspace feel coherent rather than administrative?
- Can a lesson be updated in about sixty seconds?
- Does the golfer publication feel personal, premium, and easy to retell?
- Which advanced capabilities belong in contextual menus rather than the main path?

All data is synthetic and local. Closing the server resets the scenario state.
