## Frame naming and status

Use a stable planning convention such as:

```text
FLOW / STEP / WIDTH / STATE / VERSION / STATUS
ACT / 05-PACKAGE / NARROW / INVALID-LINK / v01 / TEST
GOLFER / 07-PACKAGE / WIDE / COMPLETE / v01 / TEST
ACCOUNT / PAUSE / NARROW / READ-ONLY / v01 / CONCEPT
```

Allowed statuses: `CONCEPT`, `INTERNAL REVIEW`, `TEST`, `REVISE`, `AARON REVIEW`, `APPROVED`. Only Aaron may assign `APPROVED`, with exact version recorded.

## Global completion test

A drawn flow is complete only when:

- every named step and critical state has a linked frame;
- acquisition claims, price, trial, cancellation, and pause are labelled correctly;
- instructor required/optional/deferred content is visible;
- preview matches the golfer artifact;
- all assistance is measurable;
- responsive and accessible behavior is annotated;
- non-purchase, error, cancel, and pause paths are genuine;
- participant evidence is logged against the exact version; and
- Aaron records a decision.
